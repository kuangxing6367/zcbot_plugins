# 链接解析 (link_parser)

群/私聊消息里的链接统一解析,一个入口按平台分发:

| 链接类型 | 处理方式 | 依赖 |
| --- | --- | --- |
| B站(bilibili.com / b23.tv / BV / av) | B站官方 Web 接口,标题/UP/数据/封面 | 无(公开接口) |
| 抖音/快手/小红书/微博/西瓜/皮皮虾/梨视频/腾讯视频/YouTube | 聚合解析接口,标题/作者/互动数据/封面 | 需配置 `fengyu_api_key` |
| 其他 http(s) 链接 | 网页分析:标题/描述/风险关键词标注 | 无 |

- 自动解析带冷却(同链接默认 30 秒内不重复解析),被 @ 的消息让给 LLM 对话。
- 群内自动网页分析默认关闭,管理员发「分析 开」开启。
- 已注册为 LLM AI 函数 `parse_video`,AI 可解析用户发来的视频链接并回答。
- 视频解析不返回任何视频直链。

## 命令

| 命令 | 说明 |
| --- | --- |
| /bv <BV\|AV号> | 解析 B 站视频(别名 /av) |
| /解析 <链接> | 手动解析视频链接(别名 /视频解析) |
| /分析 <url> | 手动分析网页 |
| 分析 开\|关 | 群内自动网页分析开关(管理员) |
| /链接帮助 | 使用帮助 |

## 配置

见插件配置面板(`_conf_schema.json`),关键项:

- `fengyu_api_key`:除 B 站外的视频平台解析依赖该密钥,不配置则仅 B 站可用。
- `auto_parse` / `group_auto_parse` / `private_auto_parse`:自动解析开关(总/群/私)。
- `cooldown_seconds`:同链接自动解析冷却。

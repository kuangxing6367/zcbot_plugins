# LLM 开发助手 (llm_plugin_gen)

通过 OpenAI 兼容接口让 LLM 编写插件、管理插件文件，支持自定义人格与 skills。**全异步实现**（async handler + httpx），不占用框架线程池，多用户并发不会拖垮机器人。

采用 **Claude Code 风格工作流**：每个新需求 AI 先理解 → 规划 → 用 `ask_user` 提问，**用户批准后才动手**。

## ⚠️ 安全警告（务必阅读）

本插件赋予 LLM **主机文件系统的完整读写删权限**（`ls` / `read` / `search` / `write` / `edit` / `append` / `mkdir` / `rename` / `rm`，不受路径限制）。LLM 可以读取主机上的任何文件，**包括但不限于**：

- 框架根目录 `config.yaml` —— 内含**数据库密码、OneBot access_token** 等敏感凭据
- 插件代码、框架源码、`data/` 数据目录、其他配置文件

由此带来的风险，**由使用者自行评估并承担**：

1. **接口不可信**：`base_url`（OpenAI 兼容接口）若不受信任，或请求流量经过第三方转发/记录，对方可能读取会话中携带的文件内容并外传你的敏感凭据。
2. **模型越权**：LLM 可能被提示词注入诱导，读取并输出敏感文件内容。

**安全使用建议**：

- 仅使用**可信**的 OpenAI 兼容接口，且通信走 HTTPS
- 不要在高权限/生产环境把 `base_url` 指向不受信任的地址
- 命令**仅超级管理员可用**，请勿开放给普通用户

## 用法

| 命令 | 说明 |
| ---- | ---- |
| `/ai new [标题]` | 创建新会话，自动分配两位编号（`#00`~`#99`）并自动进入 |
| `/ai <指令>` | 当前会话发起请求（无会话自动创建），例：`/ai 写一个每日早报插件` |
| `/ai #编号 <指令>` | 指定会话发起请求 |
| `/ai #编号 1~4` | 回复 AI 提问，选择第 N 个选项 |
| `/ai #编号 say <文字>` | 回复 AI 提问，自由补充说明 |
| `/ai list` | 列出所有会话（当前会话带 ▶ 标记） |
| `/ai set #编号` | 进入指定会话 |
| `/ai del [#编号]` | 删除会话（默认删除当前会话） |
| `/ai stop` | 暂停当前正在运行的会话（取消 AI 任务） |
| `/pluginlist` | 查看已加载插件 |

## 会话机制

- 每个用户最多同时存在 **100 个会话**（`#00`~`#99`）；编号用尽时自动抛弃**最旧**会话腾出编号
- 每个会话独立上下文，互不干扰；消息与用量存数据库（`llm_dev_conversations` / `llm_dev_messages` / `llm_dev_usage` 表）
- **上下文自动压缩**：消息条数或总字符超限时，旧消息交给 LLM 生成摘要、保留最近消息，避免上下文爆炸
- **函数调用不限制轮数**；AI 在每个执行节点都会用文本实时汇报进度
- 每次回复附带累计 token 消耗

## 配置项（Web UI → 插件配置）

| 键 | 说明 |
| ---- | ---- |
| `base_url` | OpenAI 兼容接口地址（必填） |
| `api_key` | 接口密钥（可空） |
| `model` | 模型名，默认 `gpt-4o-mini` |
| `temperature` | 采样温度，默认 0.3 |
| `max_tokens` | 最大输出长度，默认 8192 |
| `max_tool_rounds` | 函数调用最大轮数，默认 0（不限制） |
| `session_max_msgs` | 会话保留消息条数上限（超 2 倍触发压缩） |
| `session_max_chars` | 会话总字符压缩阈值（超 2 倍触发压缩） |
| `persona` | 自定义人格 |
| `skills` | 自定义技能列表 |
| `cwd` | LLM 文件操作基准目录（默认项目根） |

## 函数调用工具

- **文件**：`ls`（列目录/读文件/通配符）、`read`（带行号读文件）、`search`（正则搜索）、`write`（写/覆盖）、`edit`（替换）、`append`（追加）、`mkdir`（建目录）、`rename`（重命名）、`rm`（删除）
- **确认**：`ask_user`（向用户提问并等待批准，回复 `/ai #编号 N` 或 `/ai #编号 say ...`）
- **插件管理**：`load_plugin` / `unload_plugin` / `reload_plugin` / `list_plugins`
